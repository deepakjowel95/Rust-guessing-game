# This is a number guessing game built on rust

## Follow the step to run on native system
- install rust
     `curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh`
- confirm and check version
  `rustc --version`
- add environment path `echo $PATH`
---------------------------------
- Download the zip from this repository and extract file or pull the repository from your native system via terminal
---------------------------------
- Open the extracted package on terminal and paste the following command and press 'ENTER'

- `cargo run main.rs`
